# Sama's Little Universe ❤️

A private little iPhone web app (PWA) made with love by Ahmed for Sama.

- 🏠 **Home** — "صباح الفل يا سما ❤️", current cycle day, estimated next period, daily message from Ahmed
- 🌙 **Period tracker** — log start/end dates, interactive monthly calendar, history, estimates based on recorded cycles
- 🥰 **Mood tracker** — 6 moods, optional symptoms and a note per day
- 💌 **Ahmed's Corner** — 45 Egyptian Arabic messages, virtual hugs, WhatsApp draft button (never sends automatically)
- 🚨 **Emergency Cuteness Kit** — chocolate emergency button, kind words, surprise box, compliment cannon, breathing bunny
- ⚙️ **Settings** — cycle settings, Arabic/English, export/import backup, delete all data

Egyptian Arabic (RTL) by default, English optional. Works offline after the first visit.

## Privacy

- All period, mood and symptom data lives **only on the phone**, in IndexedDB.
- No backend, analytics, tracking, external fonts or third-party requests. Nothing is ever uploaded to GitHub.
- Clearing Safari website data (or deleting the Home Screen app) can erase the records — use **Settings → Export backup** now and then.
- Predictions are rough averages, **not** medical advice, contraception or fertility predictions.

> ⚠️ Don't commit backup files (`sama-backup-*.json`) to this repo — they contain health data. `.gitignore` excludes them.

## Development

```bash
npm install
npm run dev        # http://localhost:5173/Sama-/
npm test           # unit tests (cycle math, backup validation, content)
npm run build      # type-check + production build into dist/
npm run preview    # serve the production build (service worker active)
```

Stack: React + TypeScript + Vite + Tailwind CSS. The service worker is generated by a tiny plugin in
`vite.config.ts` (template in `src/sw-template.js`) — no PWA library needed.

Customize:
- Ahmed's messages: `src/data/messages.ts`
- Kit messages, coupons, compliments: `src/data/kit.ts`
- UI text (Arabic/English): `src/lib/i18n.ts`
- App icon: edit `public/icons/icon.svg`, then `node scripts/generate-icons.mjs` (needs Playwright)

## Publish on GitHub Pages

1. Merge the pull request into `main`.
2. In GitHub: **Settings → Pages → Build and deployment → Source: "GitHub Actions"** (one-time).
3. The workflow **Build, test & deploy to GitHub Pages** runs on every push to `main`
   (watch it under the **Actions** tab). You can also run it manually via **Run workflow**.
4. When it's green, the app is live at **https://ahmedsamir1.github.io/Sama-/**

## Install on Sama's iPhone

1. Open **Safari** (must be Safari) and go to `https://ahmedsamir1.github.io/Sama-/`.
2. Wait for the page to fully load once (this caches it for offline use).
3. Tap the **Share** button → **Add to Home Screen** → keep the name **Sama ❤️** → **Add**.
4. Open it from the Home Screen icon (pink heart & moon). It runs full screen and works offline.
5. Optional: **⚙️ Settings → Ahmed's WhatsApp number** so the WhatsApp buttons open Ahmed's chat directly.

Note: the Home Screen app keeps its own storage, separate from Safari tabs. Deleting the icon or clearing
website data removes the records, so export a backup occasionally (Settings → Export backup).
